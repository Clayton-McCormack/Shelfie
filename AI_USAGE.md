# AI usage

AI assistance was permitted for this assessment. I used Codex and Claude for architecture discussion, implementation assistance, debugging, testing, and documentation drafting. They also assisted with seeding the initial catalog; I deliberately shaped that catalog around the required ambiguity cases. I reviewed the resulting code, ran the application and tests locally, and am responsible for explaining the implementation and its tradeoffs.

Gemini is not a development authoring tool in this project. It is the hosted vision-language model Shelfie uses at runtime to read title and author text from numbered book-spine contact sheets.
